# Research Papers

This directory contains metadata and documentation for the research papers used by the RAG system.

The original PDF files are stored locally in `papers/` and are intentionally excluded from Git because they are copyrighted source material.

## Papers

1. **Densely Connected Convolutional Networks (DenseNet)**
   - Authors: Gao Huang, Zhuang Liu, Laurens van der Maaten, Kilian Q. Weinberger
   - Source: https://arxiv.org/abs/1608.06993

2. **EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks**
   - Authors: Mingxing Tan, Quoc V. Le
   - Source: https://arxiv.org/abs/1905.11946

3. **Grad-CAM: Visual Explanations from Deep Networks via Gradient-based Localization**
   - Authors: Ramprasaath R. Selvaraju et al.
   - Source: https://arxiv.org/abs/1610.02391

4. **Axiomatic Attribution for Deep Networks**
   - Authors: Mukund Sundararajan, Ankur Taly, Qiqi Yan
   - Source: https://arxiv.org/abs/1703.01365

5. **"Why Should I Trust You?": Explaining the Predictions of Any Classifier**
   - Authors: Marco Tulio Ribeiro, Sameer Singh, Carlos Guestrin
   - Source: https://arxiv.org/abs/1602.04938

6. **Comparative XAI Evaluation of DenseNet-121 and EfficientNet-B5 for Colorectal Histopathology Classification**
   - Project research paper.
   - PDF: `papers/NGNDAI-2026_Paper_625.pdf`
